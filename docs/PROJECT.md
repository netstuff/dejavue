## Компоненты страницы

Страница (лендинг) содержит шапку, рекламный блок (hero), описание ключевых особенностей и преимуществ, слайдер с примерами работ и подвал сайта. Также, пользователи сайта могут зарегистрироваться и получить доступ к личному кабинету.

### Шапка страницы
* Логотип компании
* Разделы сайта (страницы)
* Кнопка входа/регистрации

### Рекламный блок (hero)
* Яркое продающее изображение
* Слоган компании или рекламной акции
* Краткий рекламный текст

### Описание ключевых особенностей и преимуществ
* Все преимущества из раздела `Наши преимущества`
* Расположены в виде карточек в один или несколько рядов
* Каждая карточка содержит название преимущества
* Клик по карточке открывает модальное окно с подробным описанием преимущества

### Регистрация
* Форма регистрации содержит три поля: имя, email и captcha
* Кнопка `Зарегистрироваться` активируется после заполнения всех полей
* После успешной регистрации пользователь перенаправляется в личный кабинет
* Поддерживается регистрация через социальные сети
* Кнопка «Забыли пароль?» позволяет пользователю восстановить доступ

### Слайдер с примерами работ/продуктов
* Содержит изображения и описания различных проектов/продуктов
* Изображения перелистываются (проматываются) горизонтально
* Пользователь может перелистывать изображения бесконечно
* Клик по изображению открывает модальное окно с подробным описанием проекта/продукта

### Подвал сайта
* Ссылки на социальные сети
* Ссылки на другие страницы сайта
* Форма с подпиской на новости и обновления (поле для ввода email)
* Кнопка `Подписаться` активируется после заполнения поля email


## Управление контентом
Информация в компонентах управляется через административную панель:
* Рекламный блок (изображение, заголовок, текст)
* Пользователи (список зарегестрированных пользователей)
* Примущества (изображения, заголовок, описание)
* Портфолио (список проектов/продуктов с изображениями)
