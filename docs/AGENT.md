# Инструкция по настройке агента ИИ

В качестве дефолтного агента принят [Opencode](https://opencode.ai) (следуйте инструкциям на сайте агента)

## Установка

```bash
curl -fsSL https://opencode.ai/install | bash
```

## Получение ключа API

Для работы с агентом вы должны зарегистрироваться на сайте [opencode.ai](https://opencode.ai) и получить ключ в разделе [личного кабинета](https://opencode.ai/auth) **API-ключи**.

## Запуск агента

В папке проекта запустите команду:

```bash
opencode 
```

## Установка инструкций

Для установки предварительных (системных) инструкций для вашего проекта используйте запрос в консоли агента:

```
Load skills @skills
```

## Ограничения

Необходимо иметь в виду, что несмотря на то, что opencode предосталяет бесплатный доступ, для каждого пользователя установлено ограничение на количество запросов. Если вы достигнете лимита, агент сообщит вам об этом. Придется сделать паузу в несколько часов (от 4 до 24).
